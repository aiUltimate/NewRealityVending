# First Moderator + Worker Operating System

## Founder role

The first moderator is simultaneously:

- product manager,
- operator,
- compliance coordinator,
- QA,
- customer support,
- data analyst,
- hardware technician,
- community manager.

The objective is not to do all of this forever.

The objective is to **turn repeated work into systems**.

---

# Daily

- Review machine health.
- Review compliance alerts.
- Review inventory.
- Review transactions.
- Review incidents.
- Review customer feedback.
- Update priority queue.

---

# Weekly

- Unit economics.
- SKU performance.
- Venue performance.
- Machine failures.
- Supplier issues.
- Legal-source changes.
- Crowdfunding metrics.
- Backlog grooming.

---

# Monthly

- Public transparency report.
- Spend report.
- Risk register review.
- Product catalog review.
- Access review.
- Security review.
- Roadmap update.

# Founder Work Prioritization

Use:

```text
Impact × Urgency × Reversibility
```

High impact + irreversible = slow down.

Low impact + reversible = automate or defer.

---

# Founder Burnout Defense

Any task repeated three times should be considered for:

- checklist,
- script,
- automation,
- delegation,
- elimination.
