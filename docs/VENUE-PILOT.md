# Venue Pilot

## Goal

Validate the Pod in a real environment without prematurely scaling.

---

# Venue Requirements

Evaluate:

- legal compatibility,
- operator partnership,
- foot traffic,
- customer fit,
- hours,
- floor space,
- power,
- internet,
- security,
- staff,
- insurance,
- restocking access.

---

# Pilot Agreement Topics

A lawyer should review the actual agreement.

Topics:

- machine ownership,
- product ownership,
- revenue share,
- utilities,
- internet,
- access,
- damage,
- theft,
- maintenance,
- insurance,
- termination,
- data,
- customer complaints,
- regulatory responsibility.

---

# Pilot Metrics

## Commercial

- transactions/day,
- revenue/day,
- average order,
- gross margin,
- contribution.

## Operational

- uptime,
- errors,
- restocks,
- labor hours,
- machine incidents.

## Customer

- conversion,
- satisfaction,
- repeat rate,
- support contacts.

## Compliance

- blocked attempts,
- verification failures,
- documentation gaps,
- incidents.
