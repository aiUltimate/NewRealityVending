# Unit Economics Worksheet

## Variables

```text
T = transactions/day
A = average order value
GM = gross margin
V = venue share
P = payment cost
C = connectivity
M = maintenance
L = logistics
W = waste/shrinkage
```

## Revenue

```text
Revenue/month = T × A × 30
```

## Gross profit

```text
Gross Profit = Revenue × GM
```

## Contribution

```text
Contribution =
Gross Profit
- Venue Share
- Payment Cost
- Connectivity
- Maintenance
- Logistics
- Waste
```

## Payback

```text
Payback Months =
Machine + Installation + Initial Inventory
÷ Monthly Contribution
```

---

# Scenario Model

Always calculate:

### Conservative
Low transactions + lower margin + higher costs.

### Base
Expected transactions + expected margin + expected costs.

### Upside
High transactions + strong margin + efficient operations.

Never build the campaign around the upside scenario.

---

# Critical Metric

## Contribution per machine per day

This should become the network's primary scaling metric.

A machine that generates revenue but consumes labor and maintenance can be a negative business.
