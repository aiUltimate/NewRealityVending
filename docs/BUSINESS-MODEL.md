# Business Model

## Business Layers

### Layer 1 — Hardware

Adaptive Pod.

Revenue possibilities:
- machine sale,
- lease,
- revenue share,
- managed service.

### Layer 2 — Software

Adaptive OS.

Potential:
- monthly subscription,
- per-machine fee,
- transaction fee,
- enterprise license.

### Layer 3 — Intelligence

Adaptive Intelligence.

Potential:
- demand forecasting,
- compliance intelligence,
- analytics,
- optimization.

### Layer 4 — Product

Adaptive Formulations / approved partner products.

Potential:
- wholesale margin,
- private label,
- proprietary formulations.

---

## Recommended starting model

Do not require Adaptive to own all four layers immediately.

Start with:

```text
Technology + Hardware
        ↓
Licensed Operator
        ↓
Controlled Pilot
```

Then decide whether product ownership creates enough incremental margin to justify additional regulatory and operational exposure.

# Key Unit Economics

Track:

- revenue/machine/day,
- gross profit/machine/day,
- contribution/machine/day,
- transactions/day,
- average order value,
- SKU margin,
- venue share,
- labor hours/machine/month,
- maintenance cost,
- payment cost,
- inventory shrinkage,
- uptime.

---

# Scaling Rule

Scale only when:

```text
Observed Contribution > Required Return Threshold
```

The threshold should be set before expansion so the founder does not rationalize weak economics after spending money.
