# Security Policy

## Security principles

- Least privilege.
- Encryption where appropriate.
- Device identity.
- Secure credentials.
- Audit logs.
- Dependency updates.
- No secrets in Git.
- Fail closed on critical authorization failures.

## Report

Do not publish exploitable vulnerabilities publicly before the project has had an opportunity to investigate.

For the founder-operated phase, use the private project contact channel maintained by the repository owner.
